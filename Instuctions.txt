OBJECTIVE

The objective of this exercise is to develop a semantic analyzer for the language you designed in PEX 0, lexed in PEX 1, and parsed in PEX 2. The semantic analyzer will do simple type-checking and implement context-sensitive grammar rules (e.g., you cannot declare the same variable twice). VIDEO.

For example, let's say that you have the following lines of code in your program:

1  // Declaring a Variable
2 float x;
3 
4 // Assigning x a value
5 x = 123;
 
Your semantic analyzer should report an error on line 5 since the code is attempting to assign a float variable with an integer value.

final y x=z; - fails if y is not declared
